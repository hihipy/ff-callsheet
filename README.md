**Your whole fantasy league in one file, ready to hand to an AI.**

FF Callsheet takes a league ID and produces a single document holding every team's roster, every available free agent, and the league's own settings. You can read it yourself, or paste it into ChatGPT or Claude and ask what to do this week.
